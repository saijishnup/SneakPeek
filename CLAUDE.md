# notch-clone

Personal clone of the "Notch" teleprompter overlay (Windows, Electron).

## Memory / planning files
Planning files (planning-with-files skill) live in `memory/`:
- `memory/task_plan.md`: phases, decisions, errors
- `memory/findings.md`: research (Notch behavior, content protection facts)
- `memory/progress.md`: session log, test results

Read all three at session start. Update them after each phase.

Spec: `docs/PRD.html`. Build contract: `docs/CONTRACT.md`.

Commands: `npm start` (dev), `npm test` (importer unit), `npm run smoke` (window flags), `npm run e2e` (full app), `npm run dist` (portable exe in dist/).
